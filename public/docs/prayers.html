GET Prayers Database

/osrs/prayers

Browse the complete OSRS prayers database with effects and requirements.

📤 Example Requests

All Prayers

GET /osrs/prayers

Specific Prayer by ID

GET /osrs/prayers/1

📥 Sample Response

{ "results": [ { "id": 1, "name": "Thick Skin", "examine": "Increases your Defence level by 5%.", "wiki_name": "Thick Skin", "wiki_url": "https://oldschool.runescape.wiki/w/Thick_Skin", "icon_path": null, "members": false, "level_required": 1, "drain_rate": 0.25, "book": "prayers" } ], "total": 29, "page": 1, "limit": 25, "totalPages": 2 }

🙏 Prayer Properties

  • id - Unique prayer identifier
  • name - Prayer display name
  • examine - Prayer description/effect
  • level_required - Prayer level requirement
  • drain_rate - Prayer point drain rate
  • book - Prayer book (prayers/ancients)
  • members - Members-only prayer
