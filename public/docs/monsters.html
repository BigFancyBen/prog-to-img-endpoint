GET Monsters Database

/osrs/monsters

Browse the complete OSRS monsters database with combat stats and detailed information.

📋 Query Parameters

page number
Page number for pagination (default: 1)
max_results number
Maximum results per page (default: 25, max: 100)

🔗 Related Endpoints

GET /osrs/monsters/{id} - Get specific monster by ID
Example: /osrs/monsters/1
GET /osrs/search/monsters?q={query} - Search monsters by name
Example: /osrs/search/monsters?q=dragon

📤 Example Requests

Basic List (First 5 monsters)

GET /osrs/monsters?max_results=5

Specific Monster by ID

GET /osrs/monsters/1

Search Monsters

GET /osrs/search/monsters?q=goblin

🐉 Monster Properties

  • id - Unique monster identifier
  • name - Monster display name
  • examine - In-game examine text
  • wiki_name - Wiki page name
  • wiki_url - Full wiki URL
  • icon_path - Icon file path
  • members - Members-only monster
  • release_date - Release date
  • combat_level - Combat level
  • hitpoints - HP/Life points
  • max_hit - Maximum damage
  • attack_type - Attack style
  • attack_speed - Attack speed
  • aggressive - Attacks on sight
  • poisonous - Can poison players
  • immune_poison - Immune to poison
  • immune_venom - Immune to venom

🔍 Database Statistics

The monsters database contains 3,000 monsters from Old School RuneScape, including:

  • Regular combat monsters
  • Boss monsters and raid bosses
  • Slayer-specific creatures
  • Quest-related NPCs
  • Skill-based creatures (like trees, rocks)
  • Special event monsters

⚠️ Error Responses

404 - Monster Not Found

{ "error": true, "statusCode": 404, "message": "Monster with ID 999999 not found" }

400 - Invalid Parameters

{ "error": true, "statusCode": 400, "message": "Invalid page number" }
