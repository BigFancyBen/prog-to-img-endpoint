GET Search API

/osrs/search/{type}?q={query}

Search across items, monsters, and prayers with flexible query parameters and fuzzy matching.

🔍 Overview

The Search API allows you to search across different types of OSRS data with intelligent fuzzy matching and filtering capabilities.

Items

Search through 14,000+ items by name, examine text, or properties

/osrs/search/items?q=dragon

Monsters

Search through 3,000+ monsters by name or attributes

/osrs/search/monsters?q=demon

Prayers

Search through 29 prayers by name or effects

/osrs/search/prayers?q=protection

🔍 Search Items

GET /osrs/search/items?q={query}

Search for items by name with fuzzy matching and intelligent results.

Query Parameters

Parameter Type Required Description
q string Yes Search query (supports partial matches)

Example Requests

GET /osrs/search/items?q=dragon GET /osrs/search/items?q=sword GET /osrs/search/items?q=abyssal

👹 Search Monsters

GET /osrs/search/monsters?q={query}

Search for monsters by name with combat stats and attributes.

Example Requests

GET /osrs/search/monsters?q=demon GET /osrs/search/monsters?q=dragon GET /osrs/search/monsters?q=zombie

🙏 Search Prayers

GET /osrs/search/prayers?q={query}

Search for prayers by name or effects.

Example Requests

GET /osrs/search/prayers?q=protection GET /osrs/search/prayers?q=strength GET /osrs/search/prayers?q=smite

📊 Response Format

Search results are returned in a consistent format across all types:

{ "results": [ { "id": 4151, "name": "Abyssal whip", "examine": "A weapon from the abyss.", "icon_url": "https://oldschool.runescape.wiki/images/Abyssal_whip.png", "category": "Melee weapons" } ], "total": 1, "query": "abyssal", "type": "items" }

🚀 Features

  • Fuzzy Matching: Intelligent search that finds partial matches
  • Cross-Type Search: Search across items, monsters, and prayers
  • Fast Results: SQLite database ensures quick search times
  • Rich Data: Results include icons, examine text, and metadata
  • Consistent Format: Uniform response structure across all search types
