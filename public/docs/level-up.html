POST Level Up API

/api/level-up

Generate a level-up notification image: the skill's icon rendered at 2× the normal size, with the new level displayed next to it.

📋 Overview

The Level Up API generates a 1040×283 parchment banner PNG styled after the classic OSRS level-up notification. The skill icon is drawn on the left, with two lines of large RuneScape NPC-Chat text on the right: "Congratulations, you just advanced a <Skill> level." in dark blue and "Your <Skill> level is now N." in black. The character name and current date appear subtly in the bottom-right corner of the parchment.

📊 Request Format

The API expects a JSON payload with the following structure:

{ "username": "Zezima", "skill": "strength", "level": 73 }

The current date is rendered onto the image automatically by the server — you do not need to send it.

Parameters

Parameter Type Required Description
username string Yes Character name displayed above the skill icon.
skill string Yes Lowercase skill name (e.g. strength, slayer, runecraft). Same names accepted by /api/progress-image's xp_earned[].skill.
level number Yes New level (integer, 1–126).

📊 Response Format

Same envelope used by the other image endpoints:

{ "statusCode": 200, "body": "\"data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...\"" }

The body is a JSON-encoded string. Parse it with JSON.parse to get the raw data:image/png;base64,… URL that can be set directly as an <img> src.
